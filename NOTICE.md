Simple Pings 0.1.0

A modified version of Pings 1.4.3 by Azzurite, distributed under GNU LGPL v3.
Upstream: https://gitlab.com/foundry-azzurite/pings
Original renderer attribution to Mörill’s Pointer is retained in scripts/ping.js.

Modified 2026-09-20:
- Independent module ID, socket namespace, and release version.
- Replaced Settings Extender with native settings and keyboard bindings.
- Reworked mouse hold handling and canvas lifecycle cleanup.
- Retained libWrapper for suppressing duplicate native long-press pings.
- Retained ping art, custom images, labels, animation, and original API methods.
- Added bounded message validation, scene/level filtering, and consistent role checks.
- Fixed removal of owned pings and the API’s missing default colour constant.
- Added reduced animation when Foundry photosensitive mode is enabled.
