Simple Pings 0.1.0 provides Pings-style map markers for Foundry v14 without Settings Extender.

- Retains names, player colours, custom images, rotation, pulsing, off-screen indicators, and configurable screen-moving permissions.
- Uses native keyboard bindings and standard mouse settings.
- Requires libWrapper. Disable the original Pings module before enabling Simple Pings.
- Existing Pings preferences are not automatically imported.
